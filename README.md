# 灵魂照面 · 历史人物测试单机版

直接双击 `index.html`，用电脑的 Chrome、Edge、Safari 或 Firefox 打开即可。不需要安装 Node.js、输入命令、启动后台、购买服务器或登录账号，测试过程不连接网络。

选择秦朝、汉朝、三国、唐朝或宋朝，也可随机抽取一个朝代；再选择希望匹配的历史人物性别。每次26题，包含对应时代的情境与诗文偏好选择，匹配有史料记载的历史人物。

点选后自动跳题，可返回修改。题目显示考察维度与情境说明。结果含人物心声、人物自画像、八维能力结构（答题倾向指数）、共同底色、现实互动方式、盲点风险与建议，以及三句原创人物台词，可保存包含全部内容的PNG长图。进度尽量保存在当前浏览器本机；更换浏览器、移动文件或浏览器禁用本地存储时，记录可能无法沿用。

秦朝按统一前后的秦国人物至秦末群雄归类。为保证史料可靠，秦朝女性方向固定对应巴寡妇清，选择页与结果均说明；希望获得不同人物结果可选择不限性别或更换朝代。三国按汉末三国文化时期归类，唐朝含武周。

本程序是趣味自我探索工具，不是经过心理学验证的量表、诊断服务或对历史人物的完整评价。

## 文件交付与售卖

向用户交付 `index.html` 和使用说明即可。单机文件没有在线验证码、设备激活、付款接口或远程撤销功能，也不能可靠防止复制转发。GitHub Pages是同一文件的在线访问入口；公开链接与公开仓库不是付费访问控制。

当前适合电脑离线文件交付；手机文件预览器或聊天软件可能不执行HTML中的JavaScript。移动端可尝试GitHub Pages网页入口，是否允许在微信/小红书直接打开仍受应用外链规则影响。

文件里无任何客户名单、数据库、服务密钥或服务器数据。只有用户主动点开的史料阅读链接需要网络。

## 开发维护

`src` 保留拆分源码，`index.html` 为内嵌题库、样式、逻辑的单一文件成品。开发者运行 `node build.mjs` 构建；玩家无需安装开发环境。人物心声、性格报告和台词为本测试原创文学化表达，不是史书记载的人物原话。
